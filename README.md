# Hlidskjalf

Hlidskjalf is a high-performance study platform for candidates preparing for the Brazilian Diplomatic Service Exam (CACD), conducted by Instituto Rio Branco, the country’s diplomatic academy.

Inspired by Norse mythology, Hlidskjalf (Old Norse: Hliðskjálf, pronounced /ˈhliːðˌskjɑːlv/) is Odin’s high seat — a vantage point from which all worlds can be observed. It represents clarity, strategic perspective, and the ability to synthesize complex information across domains.

Designed for ambitious candidates, the app delivers structured content, rigorous progression, and deep retention through active recall, integrated references, and continuous validation of knowledge.

Hlidskjalf is not just about studying — it is about building the mindset required for diplomacy.
